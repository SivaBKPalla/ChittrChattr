# Speaker script — detailed Enzo deck (17 slides)

Facts about the robot. No scores.

1. **Title** — Enzo, Team 1577 Steampunk. Why this robot is so good.
2. **Team** — High school students in Raanana, Israel. They design, build, wire, and program it.
3. **Robot** — Enzo is their Crescendo robot: pick up Notes, score, climb.
4. **Notes** — Orange foam rings on the floor (and from human players). Must grab them before scoring.
5. **Rebuild** — Mid-season they took Enzo apart and rebuilt big sections.
6. **Drive** — Swerve: each corner can point and roll any direction for lining up.
7. **Intake how** — Front rollers spin, catch a Note, pull it in.
8. **Intake detail** — Inside path holds the Note so it doesn’t bounce out while moving.
9. **Note path** — Front rollers → short path → shooter. Pickup to shot without hand reload.
10. **Speaker** — Flywheels launch Notes into the Speaker.
11. **Amp** — Same robot can place Notes in the Amp; drivers choose based on the field.
12. **Climb how** — Hooks catch the stage chain and lift the robot.
13. **Climb detail** — Climb fitted so intake/shooter still work until hang time.
14. **Cameras** — Watch field tags/goals to help aim and know position.
15. **Code** — Controllers for drivers; code handles timing and targeting helpers.
16. **Fits together** — Swerve → intake → path → shooter (Speaker/Amp) → climb; cameras/code help.
17. **Close** — Rebuilds, swerve + intake, two scoring paths, climb that leaves scoring, cameras/code.
